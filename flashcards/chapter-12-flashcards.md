## Chapter 12: Full Exam Simulation and Time-Management Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | CCNA 200-301 total exam time? | 120 minutes. Exam tip: reserve 20-30 minutes of that for 2-3 simlets/simulations before budgeting the rest across MCQs and drag-and-drop items. |
| 2 | Approximate number of items on the CCNA 200-301 exam? | Roughly 90-120 mixed-format questions (varies by form). Exam tip: don't assume a fixed count — pace by time remaining, not item count remaining. |
| 3 | CCNA blueprint domain weight: IP Connectivity | 25% — the single highest-weighted domain. Exam tip: prioritize routing (static routes, OSPF) study time accordingly. |
| 4 | CCNA blueprint domain weight: Network Fundamentals | 20%. Exam tip: tied with Network Access as second-highest weight — don't neglect it despite IP Connectivity being higher. |
| 5 | CCNA blueprint domain weight: Network Access | 20%. Exam tip: covers VLANs, trunking, EtherChannel, wireless — tied for second-highest weight with Network Fundamentals. |
| 6 | CCNA blueprint domain weight: Security Fundamentals | 15%. Exam tip: mid-weighted domain — don't under-study just because it's not the highest percentage. |
| 7 | CCNA blueprint domain weights: IP Services and Automation & Programmability | Both 10% each — the two lowest-weighted domains. Exam tip: still study fully since combined they're 20% of the exam. |
| 8 | Triage strategy for multiple-choice vs simlets on exam day | Answer fast multiple-choice questions first to lock in guaranteed points; flag/skip simlets to return to once MCQs are cleared. Exam tip: never let one long simlet eat time needed for many quick MCQs. |
| 9 | Best practice before dragging items in a drag-and-drop question | Identify the underlying logical pattern connecting the items (e.g., subnet mask to host count) before placing anything. Exam tip: reduces wasted re-drags and partial mismatches. |
| 10 | Testlet vs Simlet — key difference | Testlet = scenario + multiple static MCQs, no interactive device. Simlet = interactive simulated network/device requiring configuration or troubleshooting. Exam tip: simlets take far more time per item than testlets. |
| 11 | What to do with an uncertain multiple-choice question during the exam | Select your best guess, then flag/mark it for review before moving on. Exam tip: never leave it fully blank — a marked guess guarantees a chance at credit if time runs out. |
| 12 | Post-exam practice test analysis — what to do with a weak-domain score | Identify the lowest-scoring domain in the score breakdown and target additional study/labs there before the next practice attempt. Exam tip: weight remediation effort toward domains that are both low-scoring AND high blueprint weight (e.g., weak IP Connectivity is higher priority than weak Automation). |

# Chapter 8 Lab: NAT, NTP, DHCP/DNS, SNMP, Syslog, and QoS

**Estimated time:** 30 minutes

## Exercise

Packet Tracer: configure PAT (NAT overload) for a LAN to reach the internet, configure a DHCP relay agent (ip helper-address) across a router, and enable SSH replacing Telnet; verify with show ip nat translations and show ip ssh

## Key takeaway

Know exactly which NAT type, DHCP relay placement, and syslog/QoS terminology applies to each described operational scenario.

# Chapter 6 Lab: Single-Area OSPFv2 Configuration and Verification

**Estimated time:** 35 minutes

## Exercise

Packet Tracer: configure single-area OSPFv2 (area 0) across 3 routers, set router IDs with loopback interfaces, mark LAN interfaces passive, and verify full adjacency with show ip ospf neighbor

## Key takeaway

OSPF adjacency depends on matching area, subnet, hello/dead timers, and MTU — verify all four before troubleshooting further.

# Chapter 5 Lab: Routing Tables and IPv4/IPv6 Static Routing

**Estimated time:** 30 minutes

## Exercise

Packet Tracer: configure IPv4 and IPv6 static default routes between 3 routers, add a floating static backup route with AD 5, and verify with show ip route and show ipv6 route

## Key takeaway

Route selection always applies longest prefix match first; administrative distance only breaks ties between routes to the identical prefix.

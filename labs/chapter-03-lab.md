# Chapter 3 Lab: VLANs, 802.1Q Trunking, and L2 Discovery Protocols

**Estimated time:** 25 minutes

## Exercise

Packet Tracer: configure two switches with VLANs 10/20/30, build an 802.1Q trunk between them, and verify with show vlan brief, show interfaces trunk, and show cdp neighbors detail

## Key takeaway

Trunk correctness (encapsulation, allowed VLANs, matching native VLAN) is verified with show interfaces trunk, a command you must know cold.

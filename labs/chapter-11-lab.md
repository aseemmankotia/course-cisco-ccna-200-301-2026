# Chapter 11 Lab: Controller-Based Networking, REST APIs, and JSON

**Estimated time:** 20 minutes

## Exercise

Use Postman (or curl) against a public REST API sandbox to send GET/POST requests and parse the returned JSON response; identify keys, values, and nested arrays

## Key takeaway

Controller-based/SDN architecture, REST API CRUD mapping, and basic JSON parsing are the concrete, testable pieces of the automation domain.

# Chapter 10 Lab: ACLs, Layer 2 Security, and Wireless Security

**Estimated time:** 30 minutes

## Exercise

Packet Tracer: write and apply an extended ACL to block Telnet from a specific subnet to a server while permitting all other traffic, then configure port security with sticky MAC and violation shutdown on an access port

## Key takeaway

ACL type and placement (standard-near-destination, extended-near-source) plus port security violation modes are heavily tested configuration details.

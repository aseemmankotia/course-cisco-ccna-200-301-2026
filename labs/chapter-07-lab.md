# Chapter 7 Lab: First-Hop Redundancy and Route Selection Mastery

**Estimated time:** 25 minutes

## Exercise

Packet Tracer: configure HSRP between two routers sharing a virtual IP as the LAN default gateway, set priority/preempt, and fail over the active router to observe standby takeover

## Key takeaway

FHRPs like HSRP provide default-gateway redundancy through a shared virtual IP, not traffic load-balancing, unless GLBP is used.

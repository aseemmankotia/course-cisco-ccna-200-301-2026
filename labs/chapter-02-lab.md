# Chapter 2 Lab: IPv4 Subnetting, VLSM, IPv6, and Transport Protocols

**Estimated time:** 30 minutes

## Exercise

Packet Tracer + subnetting drill sheet: subnet a 192.168.10.0/24 block into VLSM subnets for 4 departments with different host counts; verify with ipconfig and show ip interface brief

## Key takeaway

Fast, accurate VLSM subnetting and knowing which transport protocol each service uses are non-negotiable exam skills.
